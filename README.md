# 🎬 DragonFilm iOS

Ứng dụng xem phim trực tuyến hiện đại, mượt mà dành cho iOS (iPhone & iPad), được xây dựng hoàn toàn bằng **SwiftUI** theo phong cách Cinema Obsidian & Gold.

## ✨ Tính Năng Nổi Bật

- 🚀 **Trải nghiệm Streaming mượt mà**: Hỗ trợ trình phát phim tùy chỉnh Native Player (HLS/m3u8) & Embed Player với tính năng tự động ghi nhớ thời gian xem (Resume Playback).
- ☁️ **Đồng bộ hóa đám mây (Cloud Sync)**: Đồng bộ lịch sử xem, phim yêu thích, danh sách xem sau giữa Web và iOS theo thời gian thực.
- 🔐 **Đăng nhập linh hoạt**: Hỗ trợ đăng nhập tài khoản DragonFilm và Đăng nhập bằng Google (Google OAuth).
- 🎨 **Giao diện Cinema Obsidian & Gold**: Thiết kế chuẩn điện ảnh với tone màu đen sâu (OLED Obsidian) và ánh vàng kim sang trọng kết hợp hiệu ứng kính mờ (Glassmorphism).
- 📅 **Lịch chiếu & Bảng xếp hạng**: Tích hợp bảng xếp hạng Netflix VN, TMDB (Hàn/Trung), AniList Trending và lịch chiếu phim theo ngày.
- 🔍 **Tìm kiếm thông minh**: Tìm kiếm phim nhanh chóng theo từ khóa, thể loại, quốc gia và diễn viên.

## 🛠 Yêu Cầu Hệ Thống

- iOS 17.0 trở lên
- Xcode 15.0+ / Xcode 16.0+
- Swift 5.9+

## 📦 Cài Đặt File IPA

1. Tải file `DragonFilm.ipa` từ mục [Releases](https://github.com/h2oskDrgn/DragonFilmiOS/releases).
2. Cài đặt trực tiếp qua **TrollStore** (không cần ký chứng chỉ) hoặc ký qua **AltStore / Sideloadly / Scarlet / SideStore**.

## 🔨 Hướng Dẫn Tự Build

Sử dụng script đóng gói tự động có sẵn:
```bash
./export_ipa.sh
```
